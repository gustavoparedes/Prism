# Reportar un problema

[Inicio de documentación](../../README.es.md) | [English](../en/reporting-problems.md)

Utiliza Issues para correcciones de documentación y reportes sin datos sensibles.
Incluye:

1. Versión exacta de la aplicación y entrada: E01, AD1, carpeta o live.
2. Versión y arquitectura de Windows; en live, si el proceso estaba elevado.
3. Pasos mínimos, resultado esperado y comportamiento observado.
4. Artefacto afectado, estado del procesamiento y diagnósticos pertinentes depurados.
5. Si el problema afecta adquisición, campos, timestamps o visualización.

No subas evidencia real, casos `.pri`, hives, credenciales, claves de licencia ni
logs privados sin depurar. Prefiere ejemplos sintéticos o un corpus público que
permita reproducirlo. Un nombre de archivo, usuario o ruta también puede ser sensible.

Si sospechas una vulnerabilidad, acuerda primero un canal privado con el
responsable en lugar de publicar detalles de explotación en un issue. Por ahora
este repositorio no ofrece fuentes del programa, binarios ni servicio de descargas.
